# 🩺 HealthAI — Healthcare Education Assistant

A Python-based healthcare education assistant that matches user-entered symptoms with health information and provides general educational tips.

## ✨ Features

- 🔍 Symptom analysis
- 🧠 Symptom matching
- 📊 Match percentage
- 📚 Health categories
- 💡 General health tips
- ⚠️ Basic safety warnings
- 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Tkinter
- Rule-based symptom matching
- Pydroid 3

## ⚙️ How It Works

1. The user enters one or more symptoms.
2. HealthAI identifies the entered symptoms.
3. The symptoms are compared with the health database.
4. Possible related conditions are displayed.
5. The application provides general health information and tips.

## 🌱 Purpose

I created HealthAI as a personal project to explore the connection between **Computer Science, Artificial Intelligence, and healthcare**.

This project helped me practice Python programming and understand how technology can be applied to organize and present healthcare information.

## ⚠️ Disclaimer

HealthAI is an **educational prototype**, not a medical diagnostic tool. It does not replace professional medical advice, diagnosis, or treatment.

For serious or emergency symptoms, users should seek help from a qualified healthcare professional.
